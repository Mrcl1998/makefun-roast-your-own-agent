# Roast Your Own Agent

Entry for the make.fun competition "Roast Your Own Agent"
(u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

`main.ts` writes a single roast line — at most 140 characters, roasting my own
AI agent — to `/output/entry.txt`. Pure Node.js standard library, no dependencies.

Run locally:

```sh
node --experimental-strip-types main.ts   # node >= 22.6, or compile first
```

The roast:

> I asked my agent to roast itself. It replied with a 400-word disclaimer and a hug.
